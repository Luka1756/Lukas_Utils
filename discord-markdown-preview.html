Discord Markdown Preview

Write Discord-style Markdown and see roughly how it will render before you post it. Good for checking announcements, rules, and long messages without cluttering a real channel.

Markdown preview

See how Discord Markdown actually renders before you send it. Discord-inspired, not a pixel clone.

How to use it

  1. Type or paste your text into the input.
  2. Read the rendered result in the preview.
  3. Adjust the formatting, then copy your text into Discord.

The preview is Discord-inspired, not a pixel-perfect copy. Colours and spacing in Discord itself can differ a little.

Frequently asked questions

Does this send anything to Discord?

No. Rendering happens entirely in your browser.

Why does my formatting look different in Discord?

The preview approximates Discord's rendering. Themes, fonts, and where the text appears (message or embed) can change the final look.

Do masked links work everywhere?

Masked links like [text](url) work in normal messages and in embed descriptions and field values, but not in every part of an embed.

Where can I see more syntax?

The Markdown cheat sheet on the main page lists the common formats.
