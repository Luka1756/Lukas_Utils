    JSON formatter

    Paste JSON to validate, pretty-print, or minify it.

    Help & FAQs2 questions
    Does it change my numbers?
    No. It re-indents the text without reading the values, so a very large number like 12345678901234567890 stays exactly as typed instead of being rounded.
    Why does it say Invalid JSON?
    The message is your browser's own. Common causes are single quotes instead of double quotes, a trailing comma, a missing quote around a key, or comments. JSON allows none of these.
    
        
    

        
    
          
    JSON to CSV
    
          
    Turn a JSON array into CSV you can paste into a spreadsheet. Each object becomes a row and each key a column.
    
          
          
          
    
            
          
    
          
    
            
            
            
          
    
          
    
          
    CSV 
    
          
    
          
    Nested lists are written into the cell as JSON. Whole numbers of 16 digits or more are kept exactly as written. The prefix option adds an apostrophe so a spreadsheet does not treat text as a formula.
    
        
    Help & FAQs5 questions
    What shapes of JSON does it accept?
    An array of objects is the usual case. An array of arrays becomes plain rows with no heading, a single object becomes one row, and an array of plain values becomes one column called value.
    What if the objects have different keys?
    The columns are all the keys found, in the order they first appear. A row that lacks a key gets an empty cell.
    What does Flatten nested objects do?
    It turns {"a":{"b":1}} into a column called a.b. With it off, the nested object is written into the cell as JSON. Lists are always written into the cell as JSON.
    Will long ID numbers be damaged?
    No. Whole numbers of 16 digits or more are read as text and written exactly as typed, so Discord IDs written as numbers keep every digit. Some spreadsheets still round long numbers when they open the file, so format the column as text there.
    What does the formula option do?
    A spreadsheet may treat a cell that starts with =, +, - or @ as a formula. Turning this on adds an apostrophe in front of such cells. It changes your data slightly, so leave it off unless you will open the file in a spreadsheet and do not trust the source.

    These are encodings, not encryption. Anyone can reverse them, so they don't protect private data.
    
        
    Help & FAQs5 questions
    Is Base64 encryption?
    No. Encoding changes how data is written so it can travel safely, and anyone can decode it with no key. Encryption needs a secret key to read it. Do not use Base64, hex or ROT13 to hide passwords or private data.
    Why does decoding say the bytes are not readable text?
    Base64, hex and binary decode to bytes, and this tool shows them as UTF-8 text. Data such as an image or a file is valid Base64 but not text, so it cannot be shown here.
    What is the difference between Base64 and Base64 (URL-safe)?
    URL-safe uses - and _ instead of + and / and leaves off the = padding, so it is safe in links and file names. Decoding accepts either form, with or without padding.
    Does it handle emoji and accents?
    Yes. Text is turned into UTF-8 bytes first, so non-English characters and emoji round-trip correctly in the byte formats (Base64, hex, binary).
    Which format escapes text for JSON or HTML?
    "JSON string" escapes quotes, backslashes and line breaks so the text can sit inside a JSON string. "HTML entities" escapes & < > " ' so text can sit inside HTML.

    JWT decoder
    
          
    Read the header and claims inside a JSON Web Token. This only decodes it. It does not check the signature, so don't treat the contents as trusted.
    
          
          
          
    
          
    
            
    
            
    
            
    
              
    Header
    
              
    Payload
    
            
    
            
    Signature (not verified)
    
          
    
          
    
          
    Tokens are decoded in your browser and never saved or sent. Treat a real token like a password anyway: don't paste live ones into places you don't trust.
    
        
    Help & FAQs4 questions
    Does it check that the token is genuine?
    No. Anyone can write a token with any contents. Verifying the signature needs the key, which this tool does not have, so it only reads what is inside.
    Is a JWT encrypted?
    A normal signed JWT is only encoded, so its contents are readable by anyone who has it. That is why you can read it here. A token with five parts is an encrypted one (JWE) and cannot be read without the key.
    Is it safe to paste a real token?
    It is decoded in your browser and never saved or sent. Even so, treat a real token like a password and avoid pasting live ones into places you do not trust.
    How are the dates worked out?
    iat, nbf and exp are seconds since 1970. The tool shows them in UTC and your own time, and says whether the token has expired. A value that looks like milliseconds is flagged.

    Runs in your browser's JavaScript engine, so other languages can differ in lookbehind, named groups and flags. A pattern that takes more than about two seconds is stopped.
    
        
    Help & FAQs5 questions
    Will my pattern work in Python, PHP or another language?
    Not always. This runs in your browser's JavaScript engine, so lookbehind, named groups, flags and some escapes can differ in other languages.
    Why does it say the pattern took too long?
    Some patterns, like nested quantifiers (a+)+, can take enormous time on some text. After about two seconds the test is stopped so the page does not freeze.
    What do the flags mean?
    g all matches, i ignore case, m multiline, s dot matches newline, u unicode and y sticky. Type them together, like gi.
    How do I use groups in a replacement?
    $1, $2 insert groups, $& the whole match and $<name> a named group.
    Are there limits?
    Test text up to 100,000 characters, and only the first 500 matches are listed.
    
        
    

        
    
          
    Cron explainer
    
          
    Paste a standard five-field cron expression to read it in plain words and see when it runs next.
    
          
          
          
    
            
          
    
          
    
          
    In words
    
          
    Next runs
    
          
    
          
    Fields are minute, hour, day of month, month and day of week. Names such as MON or JAN and the shortcuts @hourly, @daily, @weekly, @monthly and @yearly work. When both day fields are set, a day matches if either one does, as in standard cron. Seconds, ? L W and # (Quartz and Spring) are not supported. Your server's own time zone decides when a real job runs.
    
        
    Help & FAQs5 questions
    What are the five fields?
    In order: minute (0-59), hour (0-23), day of month (1-31), month (1-12 or JAN-DEC) and day of week (0-7 or SUN-SAT, where 0 and 7 both mean Sunday). A star means every value, a comma makes a list, a dash makes a range and a slash sets a step.
    Why does a day-of-month and a weekday together run more often than expected?
    In standard cron, when both the day of month and the day of week are set (neither starts with a star), a day counts if it matches either one. So 0 0 1 * mon runs on the 1st and on every Monday.
    Does it support seconds, ? L W or #?
    No. Those belong to Quartz and Spring style cron. This tool explains the standard five-field form used by crontab, and says so if you paste something else.
    Which time zone are the next runs in?
    You can show them in your own time zone or in UTC. A real job runs in the time zone of the server or service that schedules it, so check that setting separately. Times that a clock change skips are left out.
    Why does it say no run was found?
    Some schedules can never happen, such as 31 February. It looks eight years ahead, which also covers 29 February.
    
        
    

        
    
          
    Number base converter
    
          
    Convert whole numbers between binary, octal, decimal and hex, and see which bits are set. Handles numbers larger than 64 bits.

    Help & FAQs3 questions
    How does Detect work?
    With "Detect", a 0x, 0b or 0o prefix picks hex, binary or octal, and anything else is read as decimal. If your input is hex without a prefix, choose Hexadecimal.
    What does "Name the bits as Discord permissions" do?
    It labels each set bit with the Discord permission of that number, so you can see what a permissions integer grants. Bits above 31 are shown without a name.
    Why is a negative number shown with a minus sign?
    Negative numbers are shown as a minus sign plus the number, not as two's complement, and no bits are listed for them.

    Help & FAQs2 questions
    Are the UUIDs really random?
    They come from your browser's secure random generator when it has one. Random UUIDs are not guaranteed to be unique, but a repeat is astronomically unlikely.

    Password generator
    
          
    Make random passwords or tokens. They are created on your device and are not sent or stored anywhere.
    
          
    
            
            
          
    
          
    
            
            
            
            
            
          
    
          
    
          
    Password 
    
          
    
          
    The strength figure is an estimate of how many guesses a random pick from this set would need, in bits. Longer is stronger than adding symbols. Use a different password for every account.
    
        
    Help & FAQs5 questions
    Is this random enough for a real password?
    It uses your browser's secure random generator, the same source used for encryption keys, and it avoids the small bias that a plain remainder would add. If the browser has no secure generator, the tool says so and makes nothing.
    What does the bits figure mean?
    It is an estimate of how hard a purely random pick from this character set is to guess: each extra bit doubles the work. Around 80 bits or more is very strong for most accounts. It does not measure a password you made up yourself.
    Why does every kind I ticked always appear?
    One character from each ticked kind is placed first and the rest are filled randomly, then everything is shuffled. That keeps sites with composition rules happy, and costs very little strength.
    What does "Skip look-alikes" remove?
    It removes O, 0, I, l, 1 and | from the choices, which are easy to mix up when you read or retype a password.
    Are the passwords saved or logged?
    No. They live only on this page until you generate again or leave. Copy one into a password manager straight away.

    Help & FAQs3 questions
    Is a hash the same as encryption?
    No. A hash cannot be turned back into the text, and there is no key. It is used to check that data has not changed.
    Should I hash passwords with this?
    No. Plain SHA hashes are too fast and are not suitable for storing passwords. Use a purpose-built password hashing method in your own software.
    Does my text leave the browser?
    No. It is hashed on this page with your browser's built-in crypto and not sent anywhere.

    Help & FAQs2 questions
    What counts as a change?
