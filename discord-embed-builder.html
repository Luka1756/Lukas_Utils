    How to use it
    
    
    1. Fill in the embed on the left and watch the preview on the right update.
    2. Add fields, set a colour, and check the warnings if you go over one of Discord's limits.
    3. Copy the JSON or the webhook payload from View JSON, or paste a webhook URL and press Send to Discord.
    

    
    Examples
    
    
    title: "Server rules"A title shown in bold at the top of the embed
    color: 2282478Embed colour as a decimal number; the colour picker handles this for you
    fields: [{ name, value, inline }]Up to 25 fields, optionally shown side by side
    
    
    The builder checks the common limits: title 256 characters, description 4096, field value 1024, 25 fields, and 6000 characters across the whole embed.
    

    
    Frequently asked questions
    
    
    Is my webhook URL saved?
    No. It is a password-style field, it is never stored in the browser or logged, and it is only used when you press Send. The eye button only hides it on screen.
    Which channel does the message go to?
    The channel the webhook was created for. To post somewhere else, make a webhook in that channel. To post inside a thread, add the thread ID and the message goes there.
    What is the difference between Copy JSON and Copy Webhook Payload?
    Copy JSON gives the embed object itself. The webhook payload wraps it with your message content and bot name so it can be sent to a webhook directly.
    Does the preview match Discord exactly?
    No, it is a close guide for layout and content. The embed preview shows descriptions and field text as typed and does not turn Markdown into bold or links, although Discord does. Use the Markdown preview to check formatting.
    Why did Send fail?
    The message tells you why. "Doesn't recognize that webhook" means the URL is incomplete or deleted. A rate-limit message says how long to wait. "Rejected" names the field Discord objected to. A timeout means delivery is not confirmed, so check the channel before sending again. A bot name containing "discord" or "clyde" is refused by Discord.
    What do "Inline" and "Include current timestamp" do?
    Inline fields sit side by side instead of stacked. The timestamp adds the moment you copy or send, not a fixed time, so it changes each time. A colour on its own with no other content counts as empty and is not sent.
