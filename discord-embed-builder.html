How to use it

    
  1. Fill in the embed on the left and watch the preview on the right update.
  2. Add fields, set a colour, and check the warnings if you go over one of Discord's limits.
  3. Copy the JSON or the webhook payload from View JSON, or paste a webhook URL and press Send to Discord.


    
Examples

    
title: "Server rules"A title shown in bold at the top of the embed
color: 2282478Embed colour as a decimal number; the colour picker handles this for you
fields: [{ name, value, inline }]Up to 25 fields, optionally shown side by side

    
The builder checks the common limits: title 256 characters, description 4096, field value 1024, 25 fields, and 6000 characters across the whole embed.


    
Frequently asked questions

    
Is my webhook URL saved?
No. It is a password-style field, it is not stored in the browser, and it is not logged. It is only used at the moment you press Send.
Which channel does the message go to?
The channel the webhook was created for. To post somewhere else, create a webhook in that channel and use its URL.
What is the difference between Copy JSON and Copy Webhook Payload?
Copy JSON gives the embed object itself. The webhook payload wraps it with your message content so it can be sent to a webhook directly.
Does the preview match Discord exactly?
It is a close approximation made for checking layout and content. Discord's own rendering can differ slightly.
