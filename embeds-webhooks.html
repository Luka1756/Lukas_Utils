    Help & FAQs6 questions
    Is my webhook URL saved?
    No. It is a password-style field, it is never stored in the browser or logged, and it is only used when you press Send. The eye button only hides it on screen.
    Which channel does the message go to?
    The channel the webhook was created for. To post somewhere else, make a webhook in that channel. To post inside a thread, add the thread ID and the message goes there.
    What is the difference between Copy JSON and Copy Webhook Payload?
    Copy JSON gives the embed object itself. The webhook payload wraps it with your message content and bot name so it can be sent to a webhook directly.
    Does the preview match Discord exactly?
    No, it is a close guide for layout and content. The embed preview shows descriptions and field text as typed and does not turn Markdown into bold or links, although Discord does. Use the Markdown preview to check formatting.
    Why did Send fail?
    The message tells you why. "Doesn't recognize that webhook" means the URL is incomplete or deleted. A rate-limit message says how long to wait. "Rejected" names the field Discord objected to. A timeout means delivery is not confirmed, so check the channel before sending again. A bot name containing "discord" or "clyde" is refused by Discord.
    What do "Inline" and "Include current timestamp" do?
    Inline fields sit side by side instead of stacked. The timestamp adds the moment you copy or send, not a fixed time, so it changes each time. A colour on its own with no other content counts as empty and is not sent.
    
        
    

        
    
          
    Embed & payload validator
    
          
    Paste a webhook payload, an embed, or a list of embeds. It checks Discord's size limits and common mistakes before you send anything.
    
          
    
          
          
          
    
          
      
          
      Limits checked: content 2000, up to 10 embeds, title 256, description 4096, up to 25 fields, field name 256, value 1024, footer 2048, author 256, and 6000 characters across one message's embeds. It does not check that image links load.
      
        
      Help & FAQs5 questions
      What can I paste?
      A full webhook message (an object with content or embeds), a single embed object, or a list of embeds. "Use my embed builder embed" loads the one you built above.
      What is the difference between an error and a warning?
      Errors are things Discord would reject, such as text over a limit. Warnings are things it will probably ignore, such as an unknown field name or an empty embed.
      Why is an empty field value an error here?
      Discord needs every field to have a name and a value. The Embed builder fills an empty one with an invisible character for you, but a payload you paste is checked as written.
      Why does it say my colour must be a number?
      In JSON an embed colour is a decimal number, not hex text. The message gives the number to use, for example 2282478 for #22D3EE.
      What does it not check?
      Whether links and images load, Discord rules outside size and shape (such as blocked names), and buttons or other components. Passing here is not a guarantee Discord will accept it.

      Can I send from here?
      No. This is a preview only. Use the Embed builder to send, or the Webhook code snippets tool to get a script that sends.
      Does it include my embed?
      Yes, if you have built one in the Embed builder, it appears under the message text.

      Where does the text come from?

      Help & FAQs2 questions
      What do I do with this JSON?
      Send it as the body of a POST request to your webhook URL with the header Content-Type: application/json. The Webhook code snippets tool writes that request for you.
      Why is it just {}?
      There is nothing to send yet. The text comes from the Example box and the embed from the Embed builder. A colour on its own does not count as an embed.

      Help & FAQs5 questions
      What do I replace in the snippet?
      WEBHOOK_ID and WEBHOOK_TOKEN in the URL. Better still, read the whole URL from an environment variable so it never ends up in your code.
      What does ?wait=true do?
      Discord waits until the message exists and returns it, instead of answering straight away with nothing. Use it when your script needs the sent message or a real success result.
      Why does the cURL command fail on Windows?
      The cURL snippet is written for bash or zsh. In Windows cmd, save the JSON to payload.json and use -d @payload.json instead.
      What do the JavaScript and Python snippets need?
      The JavaScript uses top-level await, so use an .mjs file or an async function (Node 18 or newer, or a browser). The Python needs the requests package.
      Have these snippets been tested against Discord?
      They are templates built from your payload, not run against a real webhook by this site. Test with a throwaway webhook in a private channel first.
      
        
      

        
      
          
      Webhook URL inspector
      
          
      Check the format of a webhook URL and see its ID, creation date and options. It never contacts Discord, so it can't tell you whether the webhook still exists.
      
          
      
            
      
            
      
          
      
          
      
          
      Anyone who has the full URL can post to that channel. If one has been shared or posted publicly, delete the webhook in Discord and make a new one. The eye only hides the URL on screen. It is never saved or sent.
      
        
      Help & FAQs4 questions
      Does it contact Discord?
      No. It only reads the text you paste, so it cannot tell you whether the webhook still exists or works.
      What counts as a valid format?
      https://discord.com/api/webhooks/ID/TOKEN, with discord.com, ptb, canary or the old discordapp.com. The ID is 17 to 20 digits and the token a long run of letters, numbers, - and _. Tokens are normally 68 characters, so a different length is flagged as possibly cut off.
      Why is the token hidden in the results?
      Only the first and last four characters are shown, so a screenshot of the results does not leak the whole token.
      My webhook URL was shared publicly. What now?
      Delete that webhook in Discord (channel settings, Integrations) and make a new one. Anyone who has the full URL can post to the channel until you do.

      Help & FAQs6 questions
      Does it upload my image?
      Only if you press Upload to ImgBB. Choosing a file just previews it on your device. Pressing the button sends the image to this site's server, which passes it on to ImgBB, a separate image host, and shows the public link only if ImgBB confirms it. Anyone who has the link can open the image, so do not upload anything private, sensitive or that belongs to someone else. ImgBB hosts it under its own terms, which this site does not control.
      Does Clear delete the uploaded image?
      No. Clearing the preview, hiding the link box or leaving the page only affects this page. The image stays on ImgBB. Copy the delete link when it is shown if you may want to remove the image later, and keep it private, because anyone who has it can delete the image.
      What does "Keep for" do?
      It asks ImgBB to delete the image automatically after 1 hour, 1 day, 7 days or 30 days. This page cannot confirm that the deletion happens. With "No automatic deletion", ImgBB's own rules decide how long it stays.
      Which files can I upload or preview, and why can an upload fail?
      Uploads take PNG, JPG, GIF and WebP up to 4 MB, sent exactly as they are, never resized or compressed. A file that looks cut short is refused. The preview also shows AVIF, BMP and SVG, up to 20 MB, but those cannot be uploaded. An upload can fail because of the limit on how often uploads can be made, ImgBB being busy or unreachable, or uploading not yet being set up on this site. The message says which, nothing is shown as uploaded unless ImgBB confirmed it, and the button cannot send the same image twice at once.
      Why does a link not load, or not download?
      The address may be wrong or the file removed, it may not be a format browsers show, or the site blocks use on other websites. If it is a page that shows the image, copy the image's own address instead. An http link may be blocked on a secure page, so try https. Showing an image is allowed for any site, but downloading needs the host to permit other websites to fetch it. If it does not, use Open in new tab and save from there. A link that loads here may still not work in Discord or for everyone.
      What does the link preview send to the other site?
      Your browser requests the image directly, so the site hosting it can see your IP address and browser details, like any web page you visit. Luka's Utils does not copy or keep it.
