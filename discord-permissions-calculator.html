Discord Permissions Calculator

Discord stores permissions as one number. Select the permissions you need to get that number, or paste a number you already have to see exactly what it allows. It is handy when building a bot invite link.

Permissions calculator

Check boxes to get a permission integer, or paste one to see what it grants. Covers Discord's standard permission set.

How to use it

  1. Tick the permissions your bot or role needs.
  2. Copy the resulting permissions integer.
  3. Use it as the permissions value in a bot invite link, or paste an existing number to decode it.

Examples

8Administrator, which grants every permission
3072View Channel (1024) plus Send Messages (2048)

Each permission is one bit, and the integer is the sum of the bits you select.

Frequently asked questions

Where does the number go?

In the permissions parameter of a bot's OAuth2 invite link, so the bot joins with exactly those permissions.

Should I just give a bot Administrator?

It is the simplest option, but it also grants everything. Giving a bot only the permissions it uses is safer.

Can I decode a number someone gave me?

Yes. Paste it in and the matching permissions are ticked.

Do channel overrides change the result?

Channel permission overrides apply on top of role permissions in Discord. This tool only builds and reads the base permissions number.
