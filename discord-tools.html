    Time

    Timestamp builder

    Pick a date, a time and any time zone, and get every Discord <t:…> tag with a live preview of how it'll actually read.

    Compare timezones

    Every format, with what it actually means

    Previews are shown in the selected time zone. Discord shows each reader these in their own zone.

    Help & FAQs6 questions
    Why does the time look different for other people?

    That is the point of the format. The tag holds one exact moment (a Unix timestamp), and Discord converts it to each reader's own time zone and language. Everyone sees the correct local time without you doing any maths.

    What do the style letters mean?

    t short time, T long time (with seconds), d short date, D long date, f short date and time, F long date with weekday and time, and R relative ("in 2 hours"). The preview on each row is only a guide: the exact wording and order depend on each reader's Discord language.

    Which time zone should I pick?

    The one you were thinking in when you typed the clock time. "9:00 PM" in Tokyo and "9:00 PM" in London are different moments. Changing the zone afterwards keeps the same moment and converts the clock time, so the Unix timestamp does not change. "My time zone" uses the zone your device reports.

    What does "that clock time does not exist" or "happens twice" mean?

    Daylight saving changes. When clocks spring forward, one hour never happens, so the tool moves your time forward to the next real moment and tells you. When clocks go back, one hour happens twice, so you can choose the first or the second. Zones without daylight saving never show this.

    Does the relative style update by itself?

    Yes. Discord refreshes relative tags while the message is on screen, so "in 5 minutes" counts down. The "Relative" preview here also refreshes while the page is open.

    Where can I use timestamp tags?

    In normal messages, and in embed descriptions and field values. Paste the tag exactly as generated, with the angle brackets. Inside inline code or a code block it shows as plain text instead of a time.

    Unix timestamp

    Paste a unix timestamp (seconds or ms) or a date, get the other one back — plus ready-to-use Discord tags.

    Help & FAQs3 questions
    How does it decide between seconds and milliseconds?

    By length. A whole number of up to 11 digits is seconds (like 1717000000), and 12 or 13 digits is milliseconds (like 1717000000000). Anything longer is rejected as not a timestamp. A leading minus sign is allowed for dates before 1970.

    Which date formats can I type?

    ISO-style dates such as 2024-05-29T12:00, and other formats your browser understands. Fractional seconds like 1717000000.5 work too. A date with a time and no zone is read in your device's time zone, while a date-only value like 2024-05-29 is read as midnight UTC. For other styles the result depends on the browser, so check the UTC line.

    Which row do I copy for Discord?

    The button copies the :f tag (short date and time). The relative tag is shown on its own row so you can copy it by hand. For all seven styles, use the Timestamp builder.

    Discord tools

    Snowflake decoder

    Works for any Discord ID — user, server, channel, or message. Paste it to see when it was created.

    Help & FAQs5 questions
    What is a snowflake?

    A 64-bit number Discord uses as a unique ID. It combines a timestamp with internal worker, process and sequence values. The timestamp counts milliseconds from the start of 2015 (the Discord epoch).

    How do I get an ID?

    Turn on Developer Mode in Discord (User Settings, Advanced). Then right-click a user, server, channel or message and choose Copy ID.

    Does it work for messages and channels too?

    Yes. Users, servers, channels, roles and messages all use the same format, so you get the moment each one was created.

    Can it tell me who owns an account?

    No. It only reveals when the ID was generated, which for an account is when it was created. It does not contact Discord.

    Why do I get an error?

    The value must be 15 to 20 digits with no spaces or letters, and no bigger than 18446744073709551615. Numbers from other services (Twitter or X IDs, for example) look similar but use a different start date, so they decode to the wrong date here.

    Discord link parser

    Paste a message or channel link (or several) to pull out the server, channel and message IDs and see when each was created.

    Help & FAQs4 questions
    Which links does it understand?

    Links on discord.com, ptb.discord.com, canary.discord.com and discordapp.com, plus discord:// links, in the form /channels/server/channel with an optional /message. Direct-message links use @me instead of a server ID. A thread link is read as a channel, because a thread has its own ID.

    Can I paste several links at once?

    Yes. Each one gets its own card and repeats are skipped. "Copy as JSON" copies all of them with their creation times.

    Does it check that the message still exists?

    No. It only reads the numbers inside the link. The date comes from the ID itself, so it also works for deleted messages and servers you are not in.

    Why does it say no links were found?

    It looks for the /channels/… pattern with 17 to 20 digit IDs. Invite links, webhook URLs and links from other sites do not match.

    Permissions calculator

    Check boxes to get a permission integer, or paste one to see what it grants. Covers Discord's standard permission set.

    Help & FAQs5 questions
    Where does the number go?

    In the permissions parameter of a bot's OAuth2 invite link, so the bot joins with exactly those permissions. The Bot invite link tool builds that link for you.

    Should I just give a bot Administrator?

    It is the simplest option, but it grants every permission and skips channel restrictions. Giving a bot only what it uses is safer.

    Can I decode a number someone gave me?

    Yes. Paste it in and the matching permissions are ticked. The box accepts digits only.

    Why does it say the number has bits with no checkbox?

    The list covers the permissions in bits 0 to 31. Discord has added permissions above that. If your number includes them, they are kept as they are when you tick or untick other boxes, but they are not named here.

    Do channel overrides change the result?

    Channel permission overrides apply on top of role permissions in Discord. This tool only builds and reads the base permissions number.

    Bot invite link

    Build the OAuth2 link that adds a bot to a server. Get the permissions number from the permissions calculator. The link is only built here, nothing is opened or sent.

    Administrator (8) grants every permission. Only ask for what the bot uses. Sign-in scopes such as identify need a redirect URI that is also saved in the Developer Portal.
    
        
    Help & FAQs5 questions
    Where do I find the application ID?
    In the Discord Developer Portal, open your application. The Application ID on the General Information page is the same number as the client ID. It is 17 to 20 digits.
    Which scopes do I need?
    bot adds the bot to a server and applications.commands lets it register slash commands. identify, guilds and email are for "sign in with Discord" and need a redirect URI.
    Why were my permissions left out?
    Permissions only apply with the bot scope. If it is not ticked, the permissions number is dropped and the tool tells you.
    What is the redirect URI for?
    It is where Discord sends the person after they approve a sign-in scope. It must match one saved in the Developer Portal exactly, or Discord will refuse the link. Plain bot invites do not need one.
    Who can use the link?
    Anyone who opens it while signed in to Discord and who has permission to manage the server they pick. The link itself carries no secret, so it is safe to share.

    Values follow Discord's documented gateway intents. Bits Discord has not assigned are kept if you paste them, and flagged.
    
        
    Help & FAQs5 questions
    What is a privileged intent?
    One Discord restricts because it exposes more data: GUILD_MEMBERS, GUILD_PRESENCES and MESSAGE_CONTENT. You switch them on in the Developer Portal as well as in your bot. Bots in many servers need Discord's approval to use them.
    Why does my bot not see message text?
    Without MESSAGE_CONTENT a bot receives messages but not their text, apart from direct messages and messages that mention it. Tick it here and in the Developer Portal.
    Where do I use the number?
    Most libraries let you pick intents by name. The raw number is for libraries and raw gateway connections that ask for it. Copy the integer and paste it where your bot sets its intents.
    What do "All non-privileged" and "All" do?
    "All non-privileged" ticks everything except the three privileged intents. "All" ticks every intent in the list. Clear unticks them all.
    What if my number has bits that are not listed?
    Bits Discord has not assigned are kept if you paste them, and flagged, so a number is never changed without you knowing.
    
        
    

        
    
          
    Role color converter
    
          
    The decimal value is what you'd paste into a bot's role color field.
    
          
    
            
            
          
    
          
    
          
    
        
    Help & FAQs4 questions
    Why does a bot ask for a number instead of a hex code?
    Many Discord API fields store a colour as one integer. Reading the hex code as a normal number gives it: #5865F2 is 5793266.
    Is the # required?
    No. 22d3ee and #22D3EE both work. The tool needs six hex digits, so three-digit shorthand like #fff is not accepted.
    Why is my black role showing no colour?
    In Discord's API a role colour of 0 means "no colour", which is what pure black #000000 converts to. Use something very close, like #010101, if you want black.
    Can I use the result in the embed builder?
    The embed builder has its own colour picker, so you only need this tool when you want the raw decimal value elsewhere, such as in code.
    
        
    

        
    
          
    CDN image URL
    
          
    Builds a Discord CDN link from an ID, and a hash if you have one.
    
          
    
            
            
    
            
    
              
              
            
    
          
    
          
    
        
    Help & FAQs3 questions
    What is the hash and where do I get it?
    A long string of letters and numbers that names one uploaded image. It is the part before .png or .gif in an existing Discord image link. Without it the tool can only give a default avatar.
    Why do I get a default avatar when I leave the hash empty?
    Accounts without a custom avatar show one of six default images, picked from the ID. The tool works out which one. Server icons and banners have no default, so they need a hash.
    What does a hash starting with a_ mean?
    It marks an animated image, so the link ends in .gif. Other hashes end in .png. The size is added as ?size=.
    
        
    

        
    
          
    Emoji tag
    
          
    Paste a custom emoji tag to inspect it, or type name:id to build one.
    
          
          
    
        
    Help & FAQs3 questions
    How do I get an emoji's tag?
    Type a backslash before the emoji in Discord, like \:wave:, and send it. Discord shows the raw <:wave:ID> tag, which you can paste here.
    Why is my animated emoji marked as not animated?
    The tool only knows an emoji is animated if the tag starts with <a:. When you type name:id, it assumes a still image. Paste the full tag to keep the animation.
    Does it contact Discord?
    Only for the small preview picture, which your browser loads from Discord's image server. The tag itself is built on this page. If the picture does not appear, the ID may be wrong or the emoji deleted.
    
        
    

        
    
          
    Invite formatter
    
          
    Paste an invite code or link to get a clean, canonical discord.gg link.
    
          
          
    
        
    Help & FAQs2 questions
    What can I paste?
    A bare code, or a link on discord.gg or discord.com/invite (discordapp.com too), with or without https:// and with an optional query string. A code is 2 to 32 letters, numbers, - or _, so custom invite names work.
    Does it tell me whether the invite works?
    No. It only tidies the format. The Invite lookup tool asks Discord whether an invite exists.
    
        
    

        
    
          
    Invite lookup
    
          
    Looks up publicly available server info for an invite. This is the one tool that contacts Discord's API — nothing happens until you tap the button.
    
          
          
          
    
        
    Help & FAQs4 questions
    What does it send to Discord?
    Only the invite code, from your browser straight to Discord's public API, when you press Look up. Nothing goes through Luka's Utils servers, and nothing is saved.
    Why does it say the invite does not exist?
    Discord answered "not found". The invite may have expired, been deleted, or been typed wrongly.
    Why does it say it could not reach Discord?
    Your browser, an extension or a network filter blocked the request, or you are offline. The Invite formatter above still works without a connection.
    Are the member numbers exact?
    No. Discord returns approximate counts, so they can differ from what you see inside the server.
