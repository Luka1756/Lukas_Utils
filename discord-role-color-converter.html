Discord Role Color Converter

Discord's colour picker shows hex codes, but embeds and many bot settings expect a decimal number. Pick a colour here to get its HEX, RGB, and decimal values and copy the one you need.

Role color converter

The decimal value is what you'd paste into a bot's role color field.

How to use it

  1. Pick a colour with the swatch or type a hex code.
  2. Read the HEX, RGB, and decimal values.
  3. Copy the decimal value for an embed or bot role colour field.

Examples

#5865F2HEX for Discord's blurple
rgb(88, 101, 242)The same colour as RGB
5793266The same colour as a decimal number

The decimal value is the hex number read as a normal integer, so #5865F2 becomes 5793266.

Frequently asked questions

Why does a bot ask for a number instead of a hex code?

Many Discord API fields store colours as a single integer. Converting the hex code gives you that integer.

Is the # required?

No. Hex codes work with or without the leading # sign.

Can I use the result in the embed builder?

Yes. The embed builder has its own colour picker, and this tool is for when you need the raw decimal value elsewhere.
