Changelog

What's changed, version by version. Older updates before v8.0 aren't tracked here.

v8.8 Styles grid width correction Latest
  • v8.7 claimed the grid could reach a 4th column on wide screens — checked the actual math and it was short by 8 pixels, so it silently stayed at 3 columns no matter how wide the window got
  • Widened the Styles/Discord Tools content area slightly so a 4th column genuinely fits, with comfortable card width to spare
  • Widened the header and footer to match, so nothing looks narrower than the content again
  • CSS-only change — script.js untouched, sidebar/mobile layout unaffected, confirmed with the full regression suite
v8.7 Search fix & Styles grid layout
  • Fixed a real UX bug: searching Styles while a category filter was active silently hid otherwise-matching results from other categories. Search now spans all categories while typing, and clearing it restores whatever category you had selected
  • Added keyword aliases to both the Styles and Discord Tools search (e.g. "gothic" finds Fraktur, "guid" finds the UUID generator) so results aren't limited to exact tool names
  • Rebuilt the Styles card grid to size itself to the available space instead of jumping between fixed breakpoints — columns now adapt smoothly to any width, cards stay evenly sized with equal gaps, and a lone last-row card no longer sits awkwardly to one side
  • Widened the Styles section slightly on very large screens so the grid can comfortably reach a 4th column
  • Mobile layout untouched — same category pills and card behavior as before
v8.6 Bug sweep
  • Fixed the Message Preview tool silently failing to render single-asterisk italics and blockquotes — the standalone Markdown Preview tool had this working, but the Message Preview used a slightly older copy of the same logic that was missing both
  • Fixed invite links with a trailing slash (a common copy-paste artifact) failing to parse in the Invite Formatter
  • Full correctness pass on the math: re-verified snowflake decoding, all 32 permission bit values, hex/RGB/decimal color conversion, Base64 UTF-8 round-tripping, UUID format, and timezone/DST calculations directly, not just visually
  • Confirmed the Invite Lookup remains the only feature that contacts an external API, and that it fails gracefully
  • Confirmed every original tool is still present and untouched — nothing was lost across the last several updates
v8.5 Responsive polish pass
  • Fixed a real mobile overflow bug — the header could exceed the viewport width on phones around 360-390px wide (the "Support server" text link plus 3 icon buttons didn't fit; it's already in the mobile menu, so removed the duplicate)
  • Fixed the Timestamp Builder's Local/UTC and 12h/24h toggle buttons, which had a fixed width sized for 2-character labels and could clip longer text like "Local"
  • Widened the header and footer to match the rest of the site's content width on large screens, instead of looking narrower than the sections below them
  • Audited spacing, wrapping, hover behavior, and background performance across desktop, tablet, and mobile — full regression pass confirmed nothing else broke
v8.4 Timezone comparison
  • Timestamp builder can now compare multiple timezones at once — searchable city/timezone picker instead of a giant dropdown
  • Each row shows local time, UTC offset, and a date badge when it crosses into a different day
  • Fully DST-aware and correctly handles midnight-crossing in both directions, using the browser's built-in timezone data — no external lookups
  • Add/remove rows freely; your list is remembered next time you visit
  • Stays connected to the rest of the tool — same presets, 12h/24h toggle, and Discord tags as before
v8.3 Changelog page
  • Added this page — a proper version history instead of a dead footer link
  • Matches the main site's theme automatically, including your saved light/dark preference
v8.2 Ambient background & interaction polish
  • Added a subtle, slow-drifting background glow and a faint grid texture for depth — fully static under reduced-motion
  • Smooth hover transitions across cards and buttons: a small lift on style/template/palette cards and primary buttons, gentle color fades on smaller pills and icons
v8.1 Quality-of-life fixes
  • The main text input now stays visible (sticky) while scrolling through Styles, Discord Tools, or anywhere else
  • Updated the support server invite link across the header, mobile menu, and footer
  • Fixed category/quick-link jumps landing partially hidden behind the sticky bars
  • Fixed a mobile-menu overlap edge case with the sticky input
v8.0 The Discord Tools update

New tools, across 9 categories

  • Time — Timestamp builder: presets, 12h/24h, local/UTC, live relative-time preview, Unix timestamp, all 7 <t:…> formats explained
  • IDs — Snowflake decoder, CDN image URL builder
  • Permissions — bidirectional calculator (checkboxes ↔ integer)
  • Colors — role color converter with a live preview pill
  • Embeds — visual embed builder with live preview and copyable JSON
  • Emojis — custom emoji tag inspector/builder
  • Invites — offline link formatter, plus an optional public info lookup
  • Text — markdown formats, templates, ANSI colors, message length, text cleaner, markdown preview, mention formatter, message preview
  • Developer — JSON formatter, Base64, UUID generator, Unix converter, webhook payload builder

Layout & navigation

  • Sidebar-style category navigation on desktop instead of one long row of tools
  • Wider layout, "Popular" quick-links, and a live tool search
  • Mobile layout unchanged — still no horizontal scrolling

Fixes

  • Fixed a page-load error that could break interactivity
  • Fixed a filter-state bug between Styles categories and the sidebar
