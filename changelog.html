    Changelog

    What's changed, version by version.

    v11.0 Embeds, link tools and tidy-up Latest
    • Embed Builder redesign — a clearer layout with up to 10 embeds in one message (tabs), quick colour choices, character counters and a live preview closer to how Discord draws embeds, including headings, quotes, lists, links and mention chips. The preview is a close guide, not a pixel copy. Presets, templates, field reordering, inline fields, JSON export and sending to a webhook all still work, and the Thread ID field is now visible
    • TinyURL shortener — shortens a web address with TinyURL. Pressing the button sends the address to this site's server and then to TinyURL, so it is described in the Privacy Policy and Terms. It needs the site owner to set it up before it works
    • IP and URL generator — random example IP addresses and web addresses for tests and mock data, made on your device
    • Query string builder — build or read lists of URL parameters, encoded correctly. Text encoder / decoder also covers Base64
    • Markdown preview — layout fixed on phones and narrow windows
    • Tool pages — tools are grouped under clearer headings on the Discord, Embeds, Formatting and Developer pages, and tool counts are no longer shown
    • Presets & Templates — uses the full width on large screens
    • Old tool pages — the six separate tool pages now redirect to the same tool inside its category page
    • Security — added security headers and a content security policy, and removed two inline handlers the policy would block. Not yet checked on the live site
    • Contact — a contact email was added to the Privacy Policy and Terms
    • Tested in a headless browser at phone, tablet and desktop widths. Not tested on real phones, Safari or Firefox, and the TinyURL link was not tested against the live service
    v10.0 The big restructure
    • New domain — Luka's Utils now lives at lukas-utils.in
    • Restructure — the single long page is now a homepage plus category pages (Discord Tools, Embeds & Webhooks, Formatting, Text Tools, Developer Tools), with Styles, Colors and Presets & Templates on their own pages. Each tool can be opened on its own and the feature dropdowns jump straight to it
    • Homepage and navigation — category panels on the homepage, a search across every tool, and a new mobile menu
    • 54 tools — including new ones such as a Text encoder / decoder, URL parser, JWT decoder, Regex tester, Cron explainer, JSON to CSV, Password generator, Number base converter, Unicode inspector and Message splitter
    • Markdown preview — a Discord-style preview next to the raw Markdown
    • Timestamps — worldwide time zones in the Timestamp generator
    • Symbols and icons — Brackets & symbols and Logos & icons, with Regional Letters and 367 flags moved under Symbols
    • Image preview, link checker and upload — checks an image link and previews it, and can upload a PNG, JPG, GIF or WebP (up to 4 MB) to ImgBB for a public link. Nothing is uploaded unless you press the button, and the Privacy Policy and Terms describe the flow
    • Embed Builder — a show/hide toggle for the webhook URL
    • Keyboard shortcuts — a shortcuts list, opened with ? or from the menu
    • Help — a "?" button on every tool and setting, plus a collapsible Help & FAQs section on each tool
    • Privacy Policy and Terms of Service — new pages, and the full changelog history is back
    • Analytics — visits are now counted with Vercel Web Analytics, and the Privacy Policy describes it
    • Fixes — embed preview links are now limited to web addresses (a javascript: link is no longer clickable), and the shortcuts list describes Esc correctly
    • Tested in a headless browser at phone, tablet and desktop widths. Not tested on real phones, Safari or Firefox
    v9.9 Bug fixes and layout polish
    • Fixed the tool menu on phones and tablets: choosing a tool left it scrolled off the top of the screen, because the menu closed after the page had already scrolled. The menu now closes first, and the menu bar lands below the Example box instead of underneath it
    • Jumps to a section (Styles, Colors, Library and the tools) are now measured from the real height of the Example box, so headings are no longer hidden under it on very narrow screens
    • Copy no longer copies error messages. If the JSON formatter, Base64 or URL encoder or the Hash tool is showing an error, Copy now says there is nothing to copy, and those messages are shown in red
    • Base64 now reads and writes UTF-8 directly, accepts URL-safe Base64 and input without "=" padding, and tells apart "not valid Base64" from "valid Base64 that isn't readable text". The URL encoder explains unpaired surrogate characters instead of failing quietly
    • Upside down, Strike, Underline, Zalgo, Zero-width and Hidden-dots styles now work on whole visible characters, so emoji families, flags and letters with accents are no longer split apart. Upside down also mirrors brackets when it reverses text
    • The Unix converter accepts fractional seconds such as 1760000000.7
    • Library: the two filter rows are now labelled Type and Source, and the save form has hints and marks Category as optional
    • Light theme: role colour previews stay on a dark Discord-style background so the colours are readable
    • Checked and found already correct, so left unchanged: counter spacing ("Message: 23 / 2000"), clipboard success and failure handling, malformed or blocked browser storage, the circled zero, character counts for emoji, large Text Diff inputs, local and UTC timestamp conversion in several time zones, relative-time updates, stale Hash results, and the built-in permission presets
    • Tested in a headless browser at 320 to 1440px widths in both themes. Not tested on real phones, Safari or Firefox
    v9.8 Presets & Templates library
    • Added a Presets & Templates library (Library in the header). Presets change only the settings they define; templates load editable content. Search it, filter by type, built-in or your own, tool and category, and open a preview before applying anything
    • 61 built-in options: 18 templates (7 embeds, 3 webhook messages, 8 Markdown messages such as announcements, rules and changelogs) and 43 presets (embed styles, permissions, role colors, Color Lab palettes, timestamps and text styles), each with a description, category and tags
    • Added a compact Presets and Templates picker inside the Embed Builder, Webhook Builder, Markdown Preview, Permissions Calculator, Role Color Converter, Timestamp Generator, Mention formatter, Color Lab and Text Styles. It shows only items that fit that tool by default, with an option to show the rest
    • Save your own presets and templates from the current state of a tool, then rename, edit, duplicate or delete them. They are stored in this browser and survive a refresh. If storage is blocked or full you get a clear message and the library stays usable for the session
    • Export your own items as a JSON backup and import one back. Imports are checked first and you see what will be added and what is skipped before anything is saved. Existing items are never overwritten: an ID clash or changed copy becomes a new item, and identical ones are skipped
    • Imported content is only ever treated as text. Webhook URLs and tokens are never saved or exported, and items containing them are rejected on import. Applying an item never sends a webhook or publishes anything
    • Tested in a headless browser at desktop and phone widths: saving, refreshing, editing, importing and exporting, invalid and hostile data, blocked storage, keyboard use, and the sidebar navigation, browser history and Embed Builder. Not tested on real phones, Safari or Firefox
    v9.7 Example box, Case Converter and layout
    • The Example box now starts empty and shows "Example" only as placeholder text. The Case Converter uses the same text, so whatever you type, paste or delete there appears in the converter immediately, with every result updating live
    • Typing in the Case Converter's own box updates the Example box too, so there is only ever one copy of the text. Clearing it clears both, and the converter shows dashes instead of copying the placeholder
    • While the Example box is empty, the style previews and their Copy buttons still use the word "Example" so the grid is never blank
    • Markdown cheat sheet and Case Converter rows now share one aligned layout: name and syntax on the left, the preview in a fixed column, and every Copy button on the right. On narrow screens the preview moves under the name while Copy stays on the right
    • Added a button in the header to hide or show the floating Example box. Hiding only hides it, so its text, font size and case choice are kept, and it stays reachable from anywhere on the page. Your choice is remembered in your browser
    • Tested in a browser at desktop and phone widths, with the keyboard and with a touch viewport. Not tested on real phones
    v9.6 Sidebar tool navigation
    • The Discord Tools sidebar now lists every tool by name, grouped under Time, Discord tools, Embeds & webhooks, Formatting and Developer tools, instead of only jumping between categories
    • Clicking a tool opens it on its own in the main area with the full width, so the Embed Builder and other larger tools have room to work. The current tool is highlighted, and "All tools" brings back the full overview
    • Switching tools only hides the others, so anything you typed in a tool is still there when you come back
    • Tools can be linked directly (for example #tool-embed), and the Popular chips, the browser's back button and bookmarks all open the right tool
    • Search now also filters the sidebar, and pressing Enter in the search box opens the first result
    • On phones the sidebar becomes a collapsible "Tools" menu that shows the current tool and closes after you pick one
    • The sidebar entries link to the existing tools. Nothing was duplicated or rewritten
    • Tested every sidebar entry in a browser, with the keyboard, and on desktop and phone widths. Not tested on real phones or in Safari
    v9.5 Standalone tool pages
    • Six tools now have their own pages: Timestamp Generator, Embed Builder, Snowflake Decoder, Permissions Calculator, Markdown Preview and Role Color Converter
    • Each page has the working tool at the top, with short instructions, examples, an FAQ and links to related tools
    • The pages reuse the same tool code as the main page, so behaviour is identical, including copy buttons, previews, validation and sending from the Embed Builder
    • Every tool is still available on the home page, which now links to the standalone pages
    • Added the new pages to the sitemap, each with its own title, description and canonical address
    • Tested each page directly in a browser, on desktop and mobile widths, with the tool actually used. Addresses are clean (no .html), set up through a small Vercel config file
    v9.4 SEO foundations
    • Every page now has its own title and description, and a canonical address pointing to the main site
    • Links shared on Discord and other platforms now show a proper preview card with a title, description and image
    • Added a sitemap and a robots file so search engines know which pages exist
    • The home page now has a main heading, and the browser tab icon is a real file
    • Corrected the intro text: it claimed nothing you type is ever sent anywhere, which stopped being true with Send to Discord. It now says when something does leave your browser
    • Nothing here guarantees search ranking. It makes the site easier for search engines to read, and indexing is up to them
    v9.3 Embed Builder: send options
    • Added an optional "Send options" section under the webhook URL: bot name, bot avatar URL and thread ID
    • Bot name and avatar are sent with the message, and also included in Copy Webhook Payload
    • A thread ID makes the message post inside that thread. The webhook still has to belong to the thread's parent channel
    • Checked before sending: names containing "discord" or "clyde" (which Discord rejects), avatar URL format, and thread ID format
    • The webhook's channel is still decided by the webhook URL itself. Discord does not allow choosing a channel without a bot
    v9.2 Embed Builder: send to Discord
    • Added a webhook URL field and a Send to Discord button to the Embed Builder, using the same embed object as the preview and JSON
    • The URL is checked before sending (https, Discord host, valid webhook path), and the embed is checked against Discord's limits and image/link URLs first
    • The status message only says "Sent" when Discord actually accepts the request. Rejections, unknown or deleted webhooks, rate limits, timeouts and network failures each get their own message
    • The webhook URL is a password-style field, is never saved to localStorage, and is never logged
    • Layout is now Send / Clear / Reset, with Copy JSON and Copy Webhook Payload moved inside "</> View JSON"
    • The site now makes two user-initiated calls to Discord: the invite lookup and this Send button. Nothing else leaves your browser
    • Tested request building, validation and every error path against a mocked Discord response. I could not post to a real webhook from my environment, so a real-channel send is worth a quick check on your end
    v9.1 Embed Builder, rebuilt as a visual editor
    • Two-panel layout: edit on the left, live Discord-style message preview on the right (stacks vertically on mobile)
    • Added fields that were missing: title URL, author URL/icon, footer icon, and a dedicated message-content box above the embed
    • Fields can now be reordered, and each one has an inline toggle
    • Added live warnings when you're over Discord's actual limits (title, description, field, footer, author length, field count, 6000-character total) — only shown when something's actually wrong, silent otherwise
    • JSON is no longer front and center — it's behind a "</> View JSON" toggle, with Copy JSON and a separate Copy Webhook Payload action

Traced it to the actual cause instead of assuming the feature was broken, then confirmed everything copies correctly

    v3.0 Eight new Discord tools

    New tools, all computed client-side with no network calls

    • Snowflake decoder — paste any Discord ID to see its exact creation timestamp
    • Timestamp generator — choose a date and time, get all 7 Discord <t:…> tag formats, and tap any format to copy it
    • Role color converter — convert between hex, decimal and RGB for role colors
    • Message length — live checks against message limits (2000, or 4000 with Nitro) and embed limits
    • Text cleaner — strips Discord Markdown (toggleable), trims trailing spaces, and collapses blank lines and double spaces
    • Emoji tag — paste <:name:id> or name:id to inspect it, get the CDN image URL, and preview the emoji
    • Permissions calculator — bidirectional: select permissions to get the integer, or paste an integer to see the selected permissions. Covers the standard 32-permission set
    • CDN image URL — builds avatar, icon and banner URLs from an ID and hash, or computes a default-avatar URL from an ID alone
