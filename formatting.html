    Help & FAQs5 questions
    Does this send anything to Discord?

    No. Rendering happens entirely in your browser, and your text is not stored.

    Why does my formatting look different in Discord?

    The preview approximates Discord. Themes, fonts and where the text appears (message or embed) change the final look, and Discord can treat edge cases differently.

    Which formatting does the preview draw?

    Bold, italic, underline, strikethrough, spoilers, inline code and code blocks, quotes, headings (# to ###), small subtext (-#), nested lists and links. It does not draw mentions, custom emoji or timestamp tags.

    Do masked links work everywhere?

    Masked links like [text](url) work in normal messages and in embed descriptions and field values, but not in every part of an embed.

    Where can I see more syntax?

    The Markdown cheat sheet lists the common formats with a live example and a copy button.

    Help & FAQs3 questions
    Where does the text come from?

    From the Example box at the top of the page. The result updates as you type there.

    What do Secret label, Hidden dots, Zero-width and Secret code do?

    Secret label wraps a spoiler in invisible spaces. Hidden dots puts a blank Braille character between every letter, and Zero-width puts an invisible space between every letter. Secret code is a spoiler around inline code. They change how text looks, but none of them hide it from anyone who copies it, and none is encryption.

    Why does the preview differ from Discord?

    It is Discord-style, not a pixel copy. Real Discord can differ on edge cases.

    Write

    Mention formatter

    Builds the raw text for a user, role, or channel mention.

    Help & FAQs2 questions
    How do I get an ID?

    Turn on Developer Mode in Discord (User Settings, Advanced), then right-click the user, role or channel and choose Copy ID.

    Will the mention definitely ping?

    Not always. A user is only pinged if they can see the channel, and a role only if it is set to mentionable. A channel mention is a clickable link and pings nobody.

    Help & FAQs3 questions
    Why do I see ␛ in the box but not when I paste?
    ␛ is how the invisible escape character is drawn on this page. The copy button includes the real one, so Discord receives it.
    Will the colours show for everyone?
    Not necessarily. They depend on the app, and some versions of Discord show the plain text or no colour. Test on the devices your readers use.
    Can I use more colours?
    This tool offers six: cyan (36), green (32), yellow (33), red (31), purple (35) and cream (37). The code ends with a reset so later text is not coloured.

    Help & FAQs4 questions
    What can I paste?
    Rows copied from a spreadsheet (tab-separated), CSV, or pipe-separated text. If any line has a tab it is used, otherwise a pipe, otherwise commas. Quoted CSV cells can contain commas.
    Why does it need a code block?
    Only a code block uses a fixed-width font, which is what keeps columns lined up. Turn the code block option off if you only want the plain table text.
    What are the limits?
    Up to 500 rows and 40 columns. If the result is over 2000 characters the tool warns you, since one message cannot hold it. The Message splitter can cut it up.
    Why do emoji and wide characters not line up?
    The tool estimates width, but Discord's font may draw emoji and wide characters differently. Keep tables to plain text if alignment matters.

    Message length
    
          
    Checks your text against Discord's message and embed limits, with a line count too.
    
          
          
    
        
    Help & FAQs3 questions
    Which limits are checked?
    Message 2000, Nitro message 4000, embed description 4096 and embed title 256. The 4000 limit is for Nitro users' own messages. Bots and webhooks stay at 2000.
    Does it match Discord's count exactly?
    It counts Unicode characters the same way across this site. If you are very close to a limit, leave a small margin.
    What if my text is too long?
    Use the Message splitter to cut it into parts that fit.
    
        
    

        
    
          
    Message splitter
    
          
    Break a long text into pieces that fit Discord's limit. It cuts at paragraphs, then lines, then sentences and words, and keeps code blocks intact across parts.
    
          
          
          
    
            
    
          
    
          
    
          
    
          
      
          
      
        
      Help & FAQs4 questions
      Where does it cut the text?
      At the last paragraph break that fits, otherwise the last line break, sentence end or space. If a single word is longer than the limit, it is cut there. It never cuts in the first quarter of a piece, so you do not get tiny parts.
      What happens to code blocks?
      If a part ends inside a code block, the block is closed at the end of that part and reopened, with its language, at the start of the next one.
      Why are parts shorter than the limit?
      Some room is kept for closing a code fence and for part markers like (1/3), and cuts prefer natural breaks over filling every character.
      Which limit should I pick?
      2000 for normal messages, bots and webhooks. 4000 only if you have Nitro and are sending the message yourself. 1024 for an embed field value and 4096 for an embed description.
      
        
      

        
      
          
      Text cleaner
      
          
      Strips Markdown, trims stray spaces, and collapses blank lines.
      
          
          
      
          
      
            Cleaned
            
      
          
      
          
        
      Help & FAQs3 questions
      What exactly does it change?
      It removes trailing spaces on each line, turns three or more line breaks into one blank line, collapses repeated spaces into one, and trims the ends. With the option on, it also removes bold, italic, underline, strikethrough, inline code and spoiler markers, quote arrows and # headings.
      Why did my indentation disappear?
      Repeated spaces are collapsed everywhere, including leading indentation. Do not run code or aligned text through the cleaner.
      What does it leave alone?
      List markers, links, and code block fences are not treated specially, and single underscores inside words are kept.
