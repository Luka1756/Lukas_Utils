Discord Snowflake Decoder

Every user, server, channel, and message on Discord has a snowflake ID, and that ID contains the exact moment it was created. Paste one in to read the date and time.

Snowflake decoder

Works for any Discord ID — user, server, channel, or message. Paste it to see when it was created.

How to use it

  1. Turn on Developer Mode in Discord: User Settings, then Advanced.
  2. Right-click a user, server, channel, or message and choose Copy ID.
  3. Paste the ID into the decoder to see its creation time.

Examples

175928847299117063Decodes to 30 April 2016, 11:18:25 UTC

The creation time is stored in the top bits of the ID, counted in milliseconds from the start of 2015 (the Discord epoch).

Frequently asked questions

What is a snowflake?

A 64-bit number Discord uses as a unique ID. It combines a timestamp with internal worker, process, and sequence values.

Can it tell me who owns an account?

No. It only reveals when the ID was generated, which for an account is when it was created.

Does it work for messages and channels too?

Yes. Users, servers, channels, roles, and messages all use the same snowflake format.

Why do I get an error?

The value must be a plain number with no spaces or letters. Copy the ID again with Developer Mode on.
